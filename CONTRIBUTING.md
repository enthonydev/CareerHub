# Contribuição e governança

Issue com critério de aceite → branch por demanda → implementação incremental → testes → atualização da documentação → revisão de código → PR → aprovação humana. Commits em português.

Nunca inclua currículo real, perfil pessoal, chaves, logs privados ou arquivos de usuário. Informe comandos executados, resultados, riscos e limites. Mudanças arquiteturais exigem decisão registrada. Ver [processo](docs/process.md).
